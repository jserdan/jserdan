## 🗂️ Portfolio Projects

### ☕ Casa Coffee — Customer Support Triage System
> **Make.com · Gemini API · Google Sheets · Gmail · Slack**

A full customer support pipeline for a fictional online coffee shop. Incoming inquiries are classified by AI into Refund, Shipping, or General — each routed differently. High-priority refunds trigger an immediate Slack escalation. A scheduled scenario monitors SLA compliance every 4 hours, and a weekly AI-generated summary report lands in the inbox every Monday morning.

**What it demonstrates:**
- Multi-branch router logic with conditional escalation
- AI classification and structured JSON output parsing
- SLA monitoring via scheduled independent scenario
- Professional HTML email templates with dynamic content
- Internal Slack alerting for ops team

---

### 📋 Hiring Pipeline — Resume Screener
> **n8n · Gemini API · Google Sheets · Gmail · Slack**

An end-to-end hiring automation triggered by a Google Form submission. The AI reads each application, compares the candidate's background against the actual job description they pasted in, and returns a structured score. Strong candidates (8–10) get an automatic interview invite. Maybe candidates (5–7) get flagged to Slack for manual review. Not a Fit candidates (1–4) receive a personalized, constructive rejection email. Every submission is logged to Google Sheets with full AI output.

**What it demonstrates:**
- Webhook-triggered workflow via Google Apps Script
- Real resume-to-job-description AI matching
- Three-tier routing with different actions per branch
- Personalized email generation per candidate tier
- Clean Google Sheets logging with status tracking
